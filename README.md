# HSK 3급 준비 사이트 · 바이브코딩 실전 기록

> **이 폴더는 "코딩 없이 코딩" 커리큘럼을 실제로 한 번 완주해보는 기록장입니다.**
> 만드는 사람: 타스 · 시작: 2026-08-04

---

## 왜 이걸 만드나

커리큘럼 문서를 쓴 사람이 정작 그 커리큘럼으로 사이트를 안 만들어봤다면, 참가자가 어디서 막힐지 알 수 없어요.

그래서 **참가자와 똑같은 조건**으로 한 번 만들어봅니다.

- 쓰는 자료는 `coding-without-coding` 문서뿐
- 코드는 직접 쓰지 않고 전부 프롬프트로
- 막힌 지점과 친 프롬프트를 전부 기록

이 폴더에 남는 건 사이트가 아니라 **"참가자가 어디서 어떻게 막히는가"** 의 기록입니다. 시즌 2 문서를 고칠 때 이게 근거가 됩니다.

## 폴더가 두 층입니다

```
hsk3-prep/          ← 데이터베이스 도구 · 자료 · 문서 · DB 비밀번호
└── web/            ← 사이트 (3회차에 여기 만듭니다). Vercel에 올라가는 곳
```

**사이트를 폴더 맨 위에 만들지 마세요.** 이미 `package.json` 과 `scripts/` 가 있어서 `create-next-app` 이 거부합니다.

나눠둔 진짜 이유는 따로 있어요 — 맨 위에는 **DB 비밀번호**가 있고, `web/` 은 통째로 배포되는 곳입니다. 자리를 나눠두면 실수로 섞일 일이 없습니다.

| 명령 | 어디서 | 뭘 |
|---|---|---|
| `npm run dev` | 맨 위 | 사이트 켜기 (`web/` 으로 알아서 들어갑니다) |
| `npm run env:sync` | 맨 위 | 공개 키만 `web/.env.local` 로 옮기기 |
| `npm run db:check` | 맨 위 | 자료 상태 확인 |

## 자료 (준비 완료)

**HSK 3.0 3급 = 973단어.** 교육부 공식 표준 기준이고, 그중 앞에서부터 100개를 넣어뒀습니다.

| 파일 | 뭐가 |
|---|---|
| [data/words-l3-001-100.csv](data/words-l3-001-100.csv) | 단어 100개 (한자·병음·품사·뜻·예문 3줄) |
| [supabase/migrations/](supabase/migrations/) | 표 4개 · 보기 1개 · 함수 1개 · 권한 |
| [scripts/](scripts/) | `db:push` `db:seed` `db:check` — 자동으로 넣고 확인 |
| [db/02-seed-words.sql](db/02-seed-words.sql) · [03](db/03-seed-examples.sql) | 손으로 하고 싶을 때 쓰는 예비용 SQL |

**단어를 더 넣을 때 SQL을 새로 만들 필요 없습니다.** `data/` 에 CSV만 놓고 `npm run db:seed` 하면 돼요.

출퇴근 10분 = 하루 10단어 = **10일치**입니다.

한자·병음·품사는 공식 목록 그대로지만, **한국어 뜻과 예문은 아직 검수 전**입니다. 테스트 베드로 쓰기엔 충분하고, 사이트가 굴러가면 그때 훑으시면 돼요.
