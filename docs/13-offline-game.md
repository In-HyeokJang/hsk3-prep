## 사장님이 원하는 것

> 참여자들이 **한 곳에 실제로 모여서**, 다같이 **이 화면 하나**를 보면서
> 게임 방식으로 진행하며 중국어를 공부한다.
>
> - 지금은 **관리자(사장님)만** 쓰는 기능
> - 사장님이 **모임장**이고 모임원을 구해서 진행 — **테스트베드 단계**
> - 나중에 잘 되면 **돈 받고 팔** 생각
> - 목적은 **HSK 3급 자격증 취득**

노트북을 TV/프로젝터에 연결. 참여자는 계정도 기기도 없습니다.

### 정해진 조건 (2026-08-10)

| | |
|---|---|
| **횟수** | **6회차** |
| **한 회** | **2시간(120분)** |
| **인원** | **6~10명** (진행자 제외) |
| 인터넷 | **있다고 봅니다.** 인터넷 없이 돌리는 것은 안 하기로 했습니다 |

## ★ 설계의 뿌리 — 아무것도 저장하지 않습니다

세 팀이 각자 다른 길로 와서 같은 결론에 닿았습니다.

**저장을 안 하면 세 문제가 한꺼번에 사라집니다.**

| 문제 | 저장하면 | 저장 안 하면 |
|---|---|---|
| 진도 오염 | 여덟 명의 답이 **사장님 개인 복습 일정**에 섞임 | 없음 |
| 관리자 잠금 | 서버(RLS)에 권한을 걸어야 함 | 새로 새는 것이 0이라 **메뉴에 링크만 안 넣으면 됨** |
| 인터넷 끊김 | 저장 실패 처리가 필요 | 읽기만 하니 상관없음 (인터넷은 있다고 봅니다) |
| 오탭 방지 | 두 번 누르기 필요 | **필요 없음** (되돌릴 것이 없음) |

### 저장하면 정확히 뭐가 망가지나

`mark_word` 는 맞히면 간격을 **1 → 3 → 7 → 16 → 35일**로 늘리고, 틀리면 `streak = 0` · **3분 뒤**로 당깁니다.

- **⑴ 모임에서 다룬 단어 100개가 사장님의 '오늘의 단어'에서 1~35일간 사라집니다.**
  사장님이 아직 못 외운 단어인데 남이 맞히면 `known` 이 되어 다시 안 나옵니다
- **⑵ 연속 4번 맞혀 35일 뒤로 잡아둔 단어를 참여자가 틀리면 넉 달치 진척이 지워집니다**
- **⑶ 오답 노트가 남의 오답으로 찹니다.** `wrong_count` 는 **줄어드는 길이 없습니다**
- **⑷ 되돌릴 수 없습니다.** `attempts` 는 **지울 권한이 아무에게도 없고**(일부러 그렇게 만든 표),
  유일한 삭제 통로는 `withdraw_account()` — **계정이 통째로 날아갑니다**

> **별표 사고가 이 일의 축소판입니다.** 별표는 **한 사람**이 눌렀는데도 복습 순서가 밀렸습니다.
> 여기는 여덟 명입니다.

`attempts` 에 `meta` 로 구분해 저장하는 방법(ㄷ)도 **함정입니다** — `my_stats` 가 구분 없이 세므로
마이그레이션 23번이 또 필요하고, 한 군데라도 빠뜨리면 **조용히 영구 오염**입니다.

## 오프라인이 유리한 지점 — 딱 정해져 있습니다

| 영역 | 오프라인 이득 | 왜 |
|---|---|---|
| **성조** | **압도적 1위** | 혼자서는 맞는지 알 방법이 없습니다. 게다가 마이크 판정은 **조용한 방과 기준 높이 측정**이 필요해서 지하철·카페에서는 못 씁니다 — **모임방이 이 기능의 유일한 제대로 된 무대입니다** |
| **발음(성모·운모)** | 1위 공동 | `pitch.ts` 는 **높낮이 곡선만** 봅니다. `sh/s` · `ü/u` · `-n/-ng` 은 판정 대상이 아예 아닙니다. **사람 귀만이 유일한 수단** |
| **듣기** | 중간 | "한 번만 재생" 압박은 혼자서는 못 만듭니다(혼자면 무한 재생) |
| **한자 쓰기** | 중간 | 종이에 쓰고 옆사람이 획을 짚는 것이 화면 판정보다 시험(쓰기)에 가깝습니다 |
| **뜻 암기 · 독해** | **낮음 — 넣지 마세요** | **혼자가 더 효율적입니다.** 숙제로 돌리고 모임 시간을 아낍니다 |

> ⚠ **참여자끼리 서로의 발음을 계속 듣는 것은 듣기 시험 준비에 도움이 안 됩니다.**
> 한국인 억양에 귀가 익습니다. **듣기 입력은 반드시 화면의 TTS**로 주고, 사람 목소리는 교정 대상으로만.

### 오프라인 모임에서 흔히 하는데 효과가 없는 것

| | 왜 |
|---|---|
| 돌아가며 한 명씩 낭독 | 실제 발화 시간이 1/N. 남 차례에는 **자기 차례 계산**만 합니다 |
| 다 같이 합창 따라 읽기 | 자기 소리가 옆사람 소리에 묻혀 **자기 오류를 못 듣습니다.** 워밍업 30초용으로만 |
| 진행자의 문법 해설 20분 | 준비 부담 최대인데 3급 어휘 습득과 연결이 약합니다 |
| 프린트 나눠주고 각자 풀기 | 1인 학습을 한 방에서 하는 것. **모일 이유가 사라집니다** |
| 매회 근황 나누기 | 3회차부터 급격히 늘어 학습 시간을 먹습니다 |

## ★ 모임을 죽이는 것은 난이도가 아니라 **노출**입니다

**개인 이름 옆에 숫자를 띄우는 순간 하위권이 안 나옵니다.** 그게 이런 모임이 죽는 1번 경로입니다.

| 장치 | 내용 |
|---|---|
| **개인 점수·순위표 없음** | 화면에 개인 이름 옆 숫자를 **절대** 띄우지 않습니다 |
| **★ 팀 점수 = 그 팀에서 맞힌 사람 수** | 한 명이 다 맞혀도 1점, 넷이 맞히면 4점. → **옆 사람을 가르치는 것이 팀에 이득**이 됩니다. 밸런스 문제의 가장 강한 답 |
| **동시 응답이 기본** | 지명해서 말시키지 않습니다. 전원이 **카드를 동시에** 듭니다. 틀려도 순간이고 남이 못 봅니다 |
| **지표를 바꿈** | 정답률이 아니라 **"오늘 처음 맞힌 것 수"**. 초보가 구조적으로 유리합니다 |
| **역할 뒤집기** | 초보-중급 짝에서 **초보가 답하고 중급이 채점자**. 중급이 답하면 초보는 구경꾼이 됩니다 |
| **마이크는 자원자만** | 강제 금지. 남 앞에서 발음하는 것이 가장 무서운 일입니다 |
| **마무리는 성적이 아니라 소득으로** | "몇 개 맞혔다"가 아니라 **"오늘 뭐 하나 건졌나"** |
| **화면이 무작위로 지목** | 사람이 지목하면 "왜 나만" 이 나옵니다 |
| **8초 무응답 자동 힌트** | 정적을 화면이 깹니다. 잘하는 사람이 대신 답할 틈을 안 줍니다 |

## 점수 규칙

| | 정한 것 | 왜 |
|---|---|---|
| **속도 점수** | **안 줍니다** | 답을 못 떠올리고 **버티는 3~5초가 기억을 만듭니다.** 속도 가점은 그 구간을 없애고, 두 번째로 빠른 사람부터 생각을 멈춥니다 |
| **제한 시간** | 10초. 안에 맞히면 **전원 같은 점수** | 카운트다운은 보이되 남은 시간은 점수에 안 들어갑니다 |
| **오답 감점** | **없습니다** | 감점이 있으면 자신 없는 사람이 카드를 안 듭니다. **찍고 정답을 보는 것이 안 하는 것보다 낫습니다** |
| **팀 편성** | **2팀 고정** (6명=3+3 · 10명=5+5) | 3팀 이상이면 점수판이 한눈에 안 읽히고 카드 세기가 어려워집니다 |
| **역전** | **마지막 경쟁 라운드만 2점 + 뒤진 팀이 주제 선택** | "마지막 판 2배"는 **탈락** — 앞 라운드를 무의미하게 만들어 초반 집중도를 깎습니다. 주제 선택권은 점수만이 아니라 **정답 경험**을 줍니다 |
| **끝나는 조건** | **라운드 수 고정** | 점수 목표제(먼저 30점)는 끝나는 시각이 예측이 안 돼 진행자가 시계만 봅니다 |

| 시간 | 분 | 무엇 | 진행자가 하는 말 |

| **37–47** | **10** | **쉬는 시간** | **못 따라오는 사람 개별 접촉 ← 이 10분이 제일 중요** |
| 47–72 | 25 | **판 2** | |
| 72–80 | 8 | 쉬는 시간 | |
| 80–105 | 25 | **판 3** | |
| 105–118 | 13 | **⑥ 성조 릴레이 (마이크)** — 자원자부터 | **발음 교정 (사람만 가능)** |
| 118–120 | 2 | 마무리 — 놓친 것 띄우고 **폰으로 찍게** + 다음 회 약속 | "오늘 뭐 하나 건졌나" |

**한 판 = 25분** (경쟁 라운드 6분 × 3 + 협동 ⑦ 6분). 2시간이면 **3판 + 마이크 시간**입니다.

> **마이크(⑥)를 맨 뒤에 뺀 이유**: 한 명씩 하는 형식이라 나머지가 기다립니다.
> 앞에 두면 지루함이 모임 전체에 퍼지고, 뒤에 두면 **하고 싶은 사람만 남아도 됩니다.**
>
> **처음 10분에 사람을 시키지 않습니다.** 지각자가 반드시 나오고,
> 첫 활동이 개인 지명이면 늦게 온 사람이 다음부터 안 옵니다.

## 6회차 커리큘럼

**모임에서 단어를 외우지 않습니다.** 외우는 건 혼자가 빠릅니다 — **숙제로 돌립니다.**
모임은 **혼자서는 못 하는 것**(성조·발음·듣기)만 합니다.

### 범위를 나누는 법

973단어를 **빈도(자주 쓰는 순)로 6등분** 하면 회차당 약 **162개**입니다.
자료에 `frequency` 칸이 이미 있어서 사이트가 그대로 잘라줄 수 있습니다.

> 주 1회 모임이면 **하루 23단어**. 그 범위를 각자 외워 오고, 모임에서 그 범위로 게임합니다.
> 버거우면 **자주 쓰는 500개까지만** 6등분(회차당 83개)해도 됩니다.
> **범위를 줄이는 것이 회차를 늘리는 것보다 낫습니다** — 못 따라오면 안 나옵니다.

### 회차별 초점

앞 회차는 **성조 감각**, 뒤로 갈수록 **듣기와 문장**으로 옮겨갑니다.

| 회차 | 초점 | 판 1 | 판 2 | 판 3 |
|---|---|---|---|---|
| **1회** | **성조 4개 감각 잡기** + 모임 규칙 익히기 | ① 성조 체조 | ① 성조 체조(어려운 것) | ⑧ 한자 가족 |
| **2회** | **두 글자 단어의 성조 짝** | ① 성조 체조 | ⑤ 빨리 손들기 | ⑧ 한자 가족 |
| **3회** | **듣기 시작** | ③ 귀로 잡기 | ① 성조 체조 | ② 빈칸 |
| **4회** | **헷갈리는 발음 짝** (`sh/s` · `ü/u` · `-n/-ng`) | ③ 귀로 잡기 | ④ 설명해서 맞히기 | ① 성조 체조 |
| **5회** | **문장 단위** | ② 빈칸 | ③ 귀로 잡기 **상급**(병음 받아쓰기) | ④ 설명해서 맞히기 |
| **6회** | **종합 · 여섯 회 통째로** | ③ 귀로 잡기 | ② 빈칸 | ⑤ 빨리 손들기 |

- **모든 판의 마지막은 ⑦ 다 같이 살리기**입니다. 진 팀도 같은 편으로 끝내고 쉬는 시간에 들어갑니다
- **① 성조 체조는 1·2회에 몰아 넣습니다.** 규칙이 제일 쉬워서 첫 모임의 어색함을 깨는 데 제일 좋습니다
- **⑥ 마이크는 매회 맨 뒤 13분** 고정
- **6회차는 1~5회에서 놓친 것으로만** 냅니다. 새 범위를 넣지 않습니다

| | |
|---|---|

| **다음 회 처음 10분** | 지난 회 놓친 것부터 다시 |

## 진행자 부담 — 사람 몫과 화면 몫

| 사람만 할 수 있는 것 | 화면이 대신해야 하는 것 |
|---|---|
| **발음 교정 (입 모양·혀 위치)** | 정답/오답 판단 **전부** |
| 못 따라오는 사람 개별 접촉 | 점수 집계 |
| 팀 편성 · 오늘 목표 | 타이머 · 남은 문제 수 |
| 분위기 · 마무리 | 문제 뽑기 · 힌트 · 정답 공개 · 소리 |
| 다음 회 약속 | **라운드 규칙 안내** (진행자가 규칙을 외우면 안 됩니다) |

> **원칙: 진행자는 화면을 넘기는 것과 발음을 고치는 것, 두 가지만 합니다.**
> 채점을 사람이 하면 90분이 안 굴러갑니다.

### 진행자 조작 — 키 5~6개 고정

| 키 | 하는 일 |
|---|---|
| `Space` · `→` | 다음 단계 / 다음 단어 |
| `←` | 이전 |
| `Enter` | 정답 한 번에 공개 |
| `1` / `2` | 팀A · 팀B 득점 (카드 든 사람 수만큼) |
| `Backspace` | 방금 점수 취소 (**없으면 진행이 멈춥니다**) |
| `F` / `Esc` | 전체화면 / 나가기 |

**형식이 바뀌어도 키가 안 바뀝니다.**
마우스도 되어야 합니다 — 큰 버튼 3개를 **반투명**으로, 3초 안 움직이면 사라지게(영상 플레이어처럼).

### ★ 정답을 미리 안 보이게 — 창을 두 개 안 만듭니다

**진행자도 참여자와 같이 봅니다.** 채점하는 자리가 아니니까요. 대신 **화면을 단계로 나눕니다.**

```
1단계  한자만            ← 다 같이 읽어봄
2단계  + 병음 (+스피커)   ← 여기서 처음 소리
3단계  + 뜻 · 예문        ← 정답
```

`Space` 로 한 단계씩. **TTS 버튼은 2단계 뒤에만 그립니다** — 소리가 곧 정답인 자리가 있습니다.

*(노트북/TV를 다르게 띄우는 것도 `BroadcastChannel` 로 가능하지만 v1 에는 필요 없습니다.)*

## 기술 — 만드는 값

| | v1 |
|---|---|
| 새 화면 | **1개** (`web/app/live/page.tsx`) |
| 새 표 | **0개** |
| 마이그레이션 | **0개** |
| 새 라이브러리 | **0개** |
| 걸리는 시간 | **하루** (반나절 코드 + **반나절 TV 앞에서 실제 확인**) |

**실제 확인이 절반입니다.** 글자 크기는 책상에 앉아서 못 정합니다 — **5m 뒤로 물러나서** 봐야 합니다.

### 큰 화면 대응

| | |
|---|---|
| **★ `px` 를 쓰면 안 됩니다** | TV 해상도를 모릅니다. 4K에서 브라우저가 3840 CSS px 로 보고하면 `px` 로 정한 글자가 **절반 크기**로 보입니다. `clamp()` + `vmin` 으로 |
| 한자 | `clamp(120px, 22vmin, 420px)` — 55" 1080p 에서 약 240px |
| 병음 | `clamp(32px, 6vmin, 110px)` · 뜻 `clamp(28px, 5vmin, 96px)` |
| 한 화면에 | **단어 하나.** 목록·표 금지. 세 줄 넘기지 않기 |
| **하단 메뉴·최대 폭** | `layout.tsx` 를 **한 글자도 안 고칩니다.** `/live` 가 `fixed inset-0 z-50` 로 화면을 통째로 덮으면 `max-w-5xl` 도 `Nav`(`z-20`)도 무력화됩니다.<br>*(라우트 그룹 레이아웃은 루트를 **대체하지 않고 중첩**돼서 소용없습니다)* |
| 덤 | `Fullscreen API` 버튼 하나면 주소창까지 사라집니다. 라이브러리 0 |
| **밝기** | **프로젝터는 밝은 화면**, TV는 어두운 쪽이 편합니다. 프로젝터는 **검정을 못 만듭니다**(빛을 안 쏘는 게 검정) — 실내등이 켜져 있으면 검정이 회색이 되어 대비가 무너집니다.<br>기본 밝은 화면 + 뒤집기 버튼. **`globals.css` 의 `@media` 는 절대 건드리지 않습니다**(지뢰) |
| `.han` | **그대로 씁니다. 필수입니다.** 다만 굵기는 **`font-bold` 까지만** — 900을 쓰면 브라우저가 가짜로 굵게 만들어 큰 글자에서 획이 뭉갭니다 |
| `.pinyin` | **여기는 손봐야 합니다.** 5m 에서 **제일 먼저 안 보이는 게 성조 기호**입니다. `/live` 전용으로 자간·줄높이를 키운 클래스 |

| | |
|---|---|

### 관리자만 쓰게 하려면

**v1 은 메뉴에 링크를 안 넣는 것으로 충분합니다.**

`/live` 가 보여주는 단어(`v_words`)는 **지금도 anon 에게 열려 있어서**, 가려서 지켜지는 정보가 **0**입니다.
`profiles.is_admin` 은 **저장 기능이 붙는 순간** 반드시 필요해지고, 그때 **서버(RLS)에** 걸어야 합니다.
지금 만들면 쓸 데 없는 칸입니다.

> ⚠ 다만 **"화면에 없다는 것은 막았다는 뜻이 아닙니다."** 이 프로젝트가 이미 겪었습니다
