# 1회차 · 아이디어 좁히기

> 처음 떠올린 생각과, 그걸 3주에 만들 수 있는 크기로 줄인 결과입니다.

---

## 처음 떠올린 것

> "중국어 HSK 3급을 따기 위한 자격증 시험 준비 사이트.
> HSK 3급 자료들을 모아서 데이터베이스에 넣어두고,
> 단어·문장·한문 문장·해석 등등 할 수 있게 도움을 주는 사이트."

좋은 출발입니다. 그런데 이대로 3회차에 들어가면 화면이 안 나와요. **"등등"이 문제**거든요.

---

## 왜 이대로는 못 만드나

"시험 준비 사이트"에 들어갈 수 있는 건 이만큼입니다.

단어 암기 · 예문 학습 · 듣기 · 독해 · 쓰기 · 문법 정리 · 모의고사 · 오답노트 · 발음 연습 · 필순 애니메이션 · 학습 통계 · 데일리 알림 · 랭킹

**전부 좋은 기능이고, 전부 3주 안에는 안 됩니다.**

2회차 문서에 이런 문장이 있어요.

> "카페 리뷰 사이트요" 정도로는 AI가 화면을 만들기 어려워요.

HSK 사이트는 그것보다 더 심합니다. 범위가 훨씬 넓거든요. 그래서 **먼저 잘라내야** 합니다.

---

## 한 줄로 좁힌 결과

```
나는 [HSK 3급 단어를 매일 조금씩 외우고 스스로 확인하는] 사이트를 만들고 싶어.
쓰는 사람은 [HSK 3급을 처음 준비하는 한국인, 출퇴근길에 폰으로 10분씩 보려고].
```

두 번째 칸이 중요합니다. **"출퇴근길에 폰으로 10분"** 이 정해지는 순간 나머지가 자동으로 정리돼요.

- 폰이 기준 → 화면은 세로 한 칸
- 10분이 기준 → 하루치는 10단어
- 출퇴근길 → 소리는 필수가 아님 (지하철에서 못 켜요)
- 혼자 씀 → 로그인·랭킹·친구 기능 없음

---

## 이번에 하는 것 / 안 하는 것

| 한다 | 왜 |
|---|---|
| 단어 목록 보기 | 사이트의 뼈대. 이게 없으면 아무것도 없음 |
| 오늘의 단어 10개 | "매일 조금씩"을 화면으로 만든 것 |
| 단어 상세 (뜻·병음·예문·해석) | "문장, 해석"을 여기서 다 해결 |
| 외움 / 모름 표시 | 4회차 기능 하나. 이게 데이터 저장 연습 |
| 간단한 퀴즈 | 5회차에 여유 있으면 |

| 안 한다 | 언제 하면 되나 |
|---|---|
| 듣기 · 발음 · 필순 | 시즌 끝나고 두 번째 사이트에서 |
| 모의고사 · 오답노트 | 단어가 다 들어간 다음 |
| 로그인 · 회원가입 | 4회차 난이도를 두 배로 만듭니다. 절대 넣지 마세요 |
| 랭킹 · 친구 | 혼자 쓰는 사이트라 필요 없음 |
| AI 챗봇 튜터 | 재미있지만 3주 커리큘럼 밖입니다 |

:::note
**"로그인 없이 어떻게 내 진도를 기억해요?"**

브라우저에 나만 아는 임시 번호를 하나 저장해두고, 그 번호로 진도를 구분합니다. 회원가입 화면도, 비밀번호도 없어요.

자세한 건 [03-data.md](03-data.md) 의 `progress` 테이블 부분에.
:::

## "한문 문장" 에 대해

처음 아이디어에 "한문 문장"이라고 적으셨는데, 이 프로젝트에서는 **중국어 예문(간체자)** 으로 갑니다.

한문(고전 한문)과 현대 중국어는 다른 언어예요. HSK는 현대 중국어 시험이라 예문도 현대 중국어입니다.

화면에는 이렇게 나옵니다.

| | |
|---|---|
| 한자 | 我决定明天去上海。 |
| 병음 | Wǒ juédìng míngtiān qù Shànghǎi. |
| 해석 | 나는 내일 상하이에 가기로 결정했다. |

**세 줄이 한 세트**입니다. 이게 "단어, 문장, 해석"의 답이에요.
