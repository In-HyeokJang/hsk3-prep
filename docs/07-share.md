기획 전체를 한 장으로 정리한 웹페이지입니다. 링크만 보내면 됩니다.

**https://claude.ai/code/artifact/37b9e5fd-1a7e-44f2-bb1d-280c46dacc28**

들어 있는 것: 먼저 정할 것 3가지 · 페이지 설계 · 6회차 진행 · 미리 아는 함정 5개 · 폴더 구조

:::caution[처음엔 나만 볼 수 있습니다]
만들어진 페이지는 **기본이 비공개**예요. 남에게 보내려면 페이지 오른쪽 위의 공유 메뉴에서 한 번 열어주셔야 합니다.

내용을 고치고 싶으면 이 대화에서 말씀하시면 됩니다. **주소는 그대로 유지되니** 이미 보낸 링크를 다시 보낼 필요 없어요.
:::

## 2. GitHub 저장소

프롬프트 기록과 실제 코드가 같이 남는 곳입니다. 진짜 자료는 여기예요.

### 만들기

```
이 폴더를 GitHub에 올려줘.
저장소 이름은 [hsk3-prep] 로, 공개로 만들어줘.
.env 파일은 올라가지 않게 확인해줘.
```

### 커밋 메시지 규칙

`kickoff-prompts.md` 에 적어두신 그대로 갑니다.

> **커밋 로그가 곧 포트폴리오예요.**

| 좋음 | 나쁨 |
|---|---|
| `기획 문서 세트 작성` | `update` |
| `3회차 뼈대 완성` | `수정` |
| `단어 CSV 100개 추가` | `fix` |
| `Supabase words 테이블 연결` | `asdf` |

6회차에 참가자에게 이 로그를 보여줄 겁니다. **"이렇게 한 걸음씩 쌓인 거예요"** 가 그날 제일 잘 통하는 말이거든요.

## 3. 커뮤니티 사이트에 붙이기 (시즌 2)

이 기록이 쌓이면 `coding-without-coding` 사이트에 회차 문서로 넣을 수 있습니다.

### 넣을 자리

```
src/content/docs/cases/hsk3.md
```

`sessions/` 가 아니라 `cases/` 로 따로 두세요. 회차 문서는 **참가자가 회차 전에 읽는 것**이고, 이건 **참가자가 아무 때나 보는 참고 사례**라 성격이 다릅니다.

### 사이드바에 걸기

`site-notes.md` 5번에 적어두신 그대로, `autogenerate` 를 쓰면 파일만 넣으면 됩니다.

```js
// astro.config.mjs
sidebar: [
  {
    label: '사례',
    items: [{ autogenerate: { directory: 'cases' } }],
  },
]
```

### 날짜에 맞춰 열기

시즌 2에서 특정 회차에 공개하고 싶으면 `site-notes.md` 6번 방식을 그대로 쓰면 됩니다.

```md
---
title: 사례 · HSK 3급 단어장
draft: true
openDate: '2026-11-04'
---
```

:::caution[cases 폴더도 워크플로우에 넣어야 합니다]
`auto-open-sessions.yml` 은 지금 `src/content/docs/sessions/` 만 훑습니다.

`cases/` 를 추가하려면 그 파일의 `for f in ...` 줄과 `git add` 줄 **두 군데**를 같이 고쳐야 해요. 한 곳만 고치면 draft는 풀리는데 커밋이 안 됩니다.
:::

## 공유하기 전 확인 3개

- [ ] `.env` 가 저장소에 안 올라갔다
- [ ] Supabase anon 키가 문서 본문에 붙어 있지 않다
- [ ] `progress` 테이블 RLS를 조였다 (남에게 링크를 줄 거라면)

세 번째는 **혼자 쓸 때는 건너뛰어도 되지만, 참가자에게 링크를 주는 순간부터는 필수**입니다.
