## 무엇을 만드나

**TV/프로젝터에 띄우고 6~10명이 다같이 보는 화면 하나.** 6회차 × 2시간.

| | |
|---|---|
| 새 화면 | **1개** (`/live`) |
| 새 표 · 마이그레이션 · 라이브러리 | **0개** |
| 요금 | 무료 안 (⚠ 유료화 항목은 아래 💰 표시) |

### ★ 이 작업의 절대 규칙 3가지

1. **아무것도 저장하지 않습니다.** `mark_word` 도 `log_attempt` 도 부르지 않습니다.
   10명의 답이 사장님 개인 복습 일정에 섞이면 **되돌릴 방법이 없습니다**
   (`attempts` 는 지울 권한이 아무에게도 없습니다)
2. **`quiz.ts` 를 그대로 재사용합니다.** 4지선다를 새로 짜면 이미 고쳐놓은 사고
   (뜻이 같은 보기 · 한자 겹침 · 정답이 둘)를 처음부터 다시 밟습니다
3. **개인 점수를 화면에 띄우지 않습니다.** 점수는 **팀 단위**, 그것도 **맞힌 사람 수**로 셉니다

## 0단계 · 화면 기반

### [ ] L1. `/live` 화면 뼈대

| | |
|---|---|
| **어디** | `web/app/live/page.tsx` (새 파일) |
| **뭘** | 단어 하나를 **3단계로 공개** — ① 한자만 → ② +병음(+스피커) → ③ +뜻·예문 |
| **★ 전체 덮기** | `fixed inset-0 z-50`. **`layout.tsx` 를 한 글자도 안 고칩니다** — 이러면 `max-w-5xl` 도 하단 메뉴(`z-20`)도 무력화됩니다.<br>*(라우트 그룹 레이아웃은 루트를 대체하지 않고 **중첩**돼서 소용없습니다)* |
| **★ 글자 크기** | **`px` 를 쓰면 안 됩니다.** TV 해상도를 모릅니다 — 4K에서 `px` 로 정하면 **절반 크기**로 보입니다.<br>한자 `clamp(120px, 22vmin, 420px)` · 병음 `clamp(32px, 6vmin, 110px)` · 뜻 `clamp(28px, 5vmin, 96px)` |
| **★ 한 화면에 단어 하나** | 목록·표 금지. 세 줄 넘기지 않기 |
| **자료** | **`getWords()` 하나만** 부릅니다. `useStore` 를 쓰면 안 됩니다 — 단어·진도·요약을 `Promise.all` 로 묶어서 **하나만 실패해도 셋 다 실패**합니다. 진도는 필요 없습니다 |
| **키보드** | `Space`·`→` 다음 · `←` 이전 · `Enter` 정답 한번에 · `F` 전체화면 · `Esc` 나가기 |
| **⚠ 키 반복** | `if (e.repeat) return` **필수.** 스페이스를 누르고 있으면 브라우저가 **초당 30번** 반복해 카드가 우수수 넘어갑니다. 기존 300ms 잠금(`study/page.tsx`)도 같이 |
| **마우스** | 큰 버튼 3개(이전/공개/다음)를 **반투명**으로, 3초 안 움직이면 사라지게 |
| **밝기** | 기본 **밝은 화면**(프로젝터는 검정을 못 만듭니다) + 뒤집기 버튼 |
| **기록** | |

### [ ] L2. `/live` 는 로그인 없이

| | |
|---|---|
| **어디** | `web/components/AuthGate.tsx` — `usePathname()` 한 줄 |
| **왜** | 토큰이 **1시간이면 만료**되고 갱신에 인터넷이 필요합니다. **2시간 모임이면 반드시 그 구간에 들어가서**, 모임 도중에 로그인 화면이 뜹니다 |
| **안전한가** | `/live` 가 읽는 `v_words` 는 **이미 anon 에게 열려 있습니다.** 새로 노출되는 것이 0입니다 |
| **기록** | |

| | |
|---|---|

### [ ] L5. ① 성조 체조 — **첫 게임**

| | |
|---|---|
| **왜 이것부터** | 화면이 할 일이 제일 적고(단어·뜻만 크게) **오프라인 이득이 제일 큽니다** |
| **규칙** | 단어와 뜻을 띄우고 짚은 글자가 몇 성인지 **몸으로**. "하나 둘 셋"에 전원 동시.<br>1성=팔 옆으로 뻗어 유지 · 2성=아래→위 · 3성=내렸다 올림(V) · 4성=위→아래 내려침 · 경성=어깨 으쓱 |
| **재사용** | `pickToneDeck` · `toneVariants` (이미 있습니다) |
| **★ 소리** | **TTS 는 정답 공개 뒤에만.** 먼저 틀면 소리가 곧 정답입니다 |

### [ ] L6. 팀 점수판
