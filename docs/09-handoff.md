### 손으로 누른 표시 ≠ 퀴즈 정답

`mark_word` 의 `p_correct` 가 세 가지 뜻을 가집니다.

```
true   퀴즈에서 맞힘   →  연속 기록 +1, 간격이 늘어남 (1 · 3 · 7 · 16 · 35일)
false  퀴즈에서 틀림   →  연속 기록 0,  3분 뒤
null   손으로 표시함   →  '외웠어요' 는 하루 뒤 (이미 더 뒤면 그대로 둠)
                          '아직이요' 는 3분 뒤 + 연속 기록 0
                          푼 횟수(seen_count)는 올리지 않음
```

**화면에서 버튼으로 표시할 때는 `correct` 를 넘기지 않습니다.** 넘기면 연타로 복습이 밀립니다.

예전에는 카드를 뒤집어 뜻을 보는 방식이었는데, 이제 문제를 냅니다.

| 뜻이 | 어떻게 나오나 |
|---|---|
| 짧고 하나 (8자 이하, `~` 없음) | **직접 입력**. `世界` → "세계" 를 칩니다 |
| 길거나 여러 개 | **4지선다**. 한 문제씩 번갈아 한자→뜻 / 뜻→한자 |

규칙은 `web/lib/quiz.ts` 한 곳에 모아뒀습니다. 채점은 너그럽습니다 —
`계속하다` 의 정답에 "계속" 만 써도 맞다고 합니다.

### 3. 반복 복습 (간격 반복)

한 번 맞히면 영영 안 나오던 것을 고쳤습니다.

```
연속 1번 맞힘 →  1일 뒤      연속 4번 →  16일 뒤
연속 2번      →  3일 뒤      그 뒤로   →  35일 뒤
연속 3번      →  7일 뒤      틀리면    →  3분 뒤부터
```

연속 정답 횟수는 새 칸을 만들지 않고 `progress.meta` 안에 `streak` 로 넣었습니다.

### 4. 로그인이 생겼습니다

**아이디로 가입합니다.** 이메일이 아닙니다.

- 가입: 아이디 · 비밀번호 · 비밀번호 확인 · **이메일 또는 전화번호**(하나는 필수)
- 아이디 · 이메일 · 전화번호는 **중복 불가**
- 탈퇴는 **소프트 삭제** — 진도는 지우고 계정 줄은 남깁니다 (재가입 방지)

## 이 프로젝트만의 중요한 구조

### 아이디는 내부적으로 가짜 주소가 됩니다

Supabase 는 원래 이메일로 로그인합니다. 아이디를 쓰려고 이렇게 바꿔 넣습니다.

```
hong1234  →  hong1234@hsk3.local
```

**화면에는 절대 안 나옵니다.** 사용자는 아이디만 봅니다.
덤으로 아이디 중복이 Supabase 차원에서도 막힙니다.

이 규칙은 `web/lib/useAuth.ts` 의 `loginEmail()` 과
`supabase/migrations/20260804080000_username.sql` 이 짝입니다. **한쪽만 고치면 안 됩니다.**

### 확인 메일을 안 보냅니다

`hong1234@hsk3.local` 로는 메일을 받을 수 없습니다.
그래서 마이그레이션 9가 계정이 만들어지는 순간 "확인 끝난 계정" 으로 표시합니다.
**Supabase 대시보드에서 Confirm email 을 켜도 이 트리거가 이깁니다.**

### 비밀번호를 잊으면 관리자가 바꿔줘야 합니다

재설정 메일을 보낼 곳이 없습니다. 가입 화면에도 그렇게 적어뒀습니다.
문의가 오면 Supabase SQL Editor 에서:

```sql
update auth.users
   set encrypted_password = extensions.crypt('새비밀번호', extensions.gen_salt('bf'))
 where email = 'hong1234@hsk3.local';
```

### 탈퇴한 계정을 되살리려면

```sql
update public.profiles set is_active = true, deleted_at = null
where username = 'hong123';
```

진도는 이미 지워졌으니 처음부터 시작합니다. 아이디만 되살아납니다.

### 못 보낸 진도는 브라우저에 쌓입니다

지하철에서 신호가 끊기면 `web/lib/pending.ts` 가 받아둡니다.
연결되면 알아서 보냅니다. 화면에는 "N개를 아직 못 보냈어요" 가 뜹니다.
