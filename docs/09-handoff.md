## 남은 일 (순서대로)

### 1. 단어 373개 더 채우기

**한 번에 100개씩, 4번 남았습니다.**

```
빈도 상위순으로 다음 100단어의 한국어 뜻과 예문을 만들어줘.
아직 뜻이 없는 단어 중에서 골라줘.
```

AI가 할 일은 이렇습니다. **순서가 중요합니다.**

| 순서 | 뭘 |
|---|---|
| 1 | DB에서 `meaning_ko is null` 인 단어를 `frequency` 순으로 100개 뽑기 |
| 2 | 한국어 뜻 · 예문 3줄을 작성해 `data/words-l3-freq-XXX-YYY.csv` 로 저장 |
| 3 | `npm run db:seed` |
| 4 | `npm run db:check` |

:::danger[영어 뜻을 그대로 믿지 마세요]
`words.meaning_en` 에 사전에서 가져온 영어 뜻이 들어 있지만, **첫 번째 뜻이 그 급수에서 쓰는 뜻이라는 보장이 없습니다.**

실제로 이런 것들이 있었습니다.

| 한자 | 영어 뜻이 말한 것 | 실제로 필요한 뜻 |
|---|---|---|
| 白 | surname Bai | 헛되이 |
| 保 | Bulgaria | 지키다 |
| 只 | grain that has begun to ripen | 마리 (양사) |
| 时代 | Time, US weekly news magazine | 시대 |
| 现代 | Hyundai, South Korean company | 현대 |

**`pos`(품사) 를 기준으로 뜻을 고르세요.** 영어는 참고만 합니다.
:::

### 3. 예문 검수

600개(그리고 곧 973개)의 뜻과 예문은 **아직 사람이 안 봤습니다.** 한자·병음·품사는 공식 목록 그대로라 믿을 수 있지만, 한국어 뜻과 예문은 새로 만든 것입니다.

검수한 단어는 이렇게 표시합니다.

```sql
update public.words set verified = true, verified_at = now()
where id in ('L3-0001', 'L3-0002');
```

시드를 다시 돌려도 이 표시는 지워지지 않습니다. 일부러 그렇게 만들었어요.

## 다시 밟으면 안 되는 지뢰

전부 실제로 한 번씩 겪은 것들입니다.

| | 어떻게 되나 | 어떻게 피하나 |
|---|---|---|
| `progress` 를 `insert` 로 저장 | 두 번째 클릭에 `409` | `upsert` + `onConflict: 'user_key,word_id'`. 지금은 `mark_word` 함수를 씀 |
| `v_words` 를 그냥 `drop` | `cannot drop view ... depend on it` | `drop view ... cascade` |
| 마이그레이션을 한 번만 돌려보고 넘어감 | **두 번째 실행에서만** 터짐 | 고친 뒤 반드시 두 번 연속 실행 |
| Tailwind `@theme` 을 미디어 쿼리 안에 | 낮에도 밤에도 어두운 화면 | `@media` 안에서는 `:root` 로 변수만 다시 정의 |
| 고쳤는데 화면이 그대로 | 옛 서버가 예전 빌드를 주고 있음 | 서버를 껐다 켠다. CSS 파일 이름이 그대로면 새 빌드가 아님 |
| 사이트를 폴더 맨 위에 만들기 | `create-next-app` 이 거부 | 사이트는 `web/` 안에. 맨 위는 DB 도구 자리 |
| CSV 값 안에 반각 쉼표 | 칸이 밀림 | 중국어 문장부호(`，`)는 괜찮고 `,` 만 피함 |
| `204` 를 성공으로 읽기 | 권한에 막혀도 성공처럼 보임 | 바꾼 뒤 **다시 읽어서** 확인 |

## 자주 쓰는 명령

폴더 맨 위(`c:\workspace\hsk3-prep`)에서 실행합니다.

| 명령 | 뭘 |
|---|---|
| `npm run db:check` | 지금 몇 개인지 · 한자 안 깨졌는지 · 권한 · 함수 |
| `npm run db:seed` | `data/` 의 CSV를 DB에 반영 (몇 번을 돌려도 같음) |
| `npm run db:push` | 스키마 변경 반영 |
| `npm run dev` | 사이트 켜기 → `localhost:3000` |
| `npm run env:sync` | 공개 키만 `web/.env.local` 로 옮기기 |
| `npm run icons` | PWA 아이콘 다시 그리기 |
