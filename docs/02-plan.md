# 2회차 · 페이지 설계

> 2회차의 결과물인 **페이지 목록 문서**입니다.
> 3회차에 이 파일을 그대로 AI에게 주면 화면이 만들어집니다.

---

## 페이지 3덩어리

```
홈 /
단어장 /words  →  단어 상세 /words/[id]
학습 /study
```

맨 위에 메뉴를 두고 셋을 다 걸어둡니다. 상세는 단어장의 짝이라 한 덩어리로 봅니다.

---

## 1. 홈 `/`

**여기서 하는 일:** 오늘 뭘 하면 되는지 한눈에 보기

| 위에서부터 | 뭐가 들어가나 |
|---|---|
| 맨 위 | 사이트 제목 · 메뉴 3개 |
| 인사말 | "오늘의 10단어" 라는 제목과 오늘 날짜 |
| 진도 막대 | 전체 중 몇 개를 외웠는지 (예: 120 / 600) |
| 오늘의 단어 카드 10개 | 한자 · 병음 · 뜻 한 줄 |
| 카드 아래 | "학습 시작" 버튼 → `/study` 로 |

**카드를 누르면** 그 단어의 상세 페이지로 넘어갑니다.

:::note
**"오늘의 10개"는 어떻게 고르나요?**

3회차에는 그냥 앞에서 10개를 자릅니다. 4회차에 진도가 저장되기 시작하면 "아직 안 외운 것 중에서 10개"로 바꿉니다.

처음부터 똑똑하게 만들려고 하지 마세요. 3회차에 그거 하다가 하루가 갑니다.
:::

---

## 2. 단어장 `/words`

**여기서 하는 일:** 전체 단어를 훑어보고 찾기

| 위에서부터 | 뭐가 들어가나 |
|---|---|
| 맨 위 | 검색창 (한글 뜻 · 병음으로 검색) |
| 그 아래 | 거르개 3개 — 전체 / 외움 / 모름 |
| 목록 | 단어 한 줄에 하나씩. 한자 · 병음 · 뜻 · 외움 표시 |

**한 줄을 누르면** 상세로 넘어갑니다.

:::caution[검색은 한글과 병음으로만]
한자로 검색하는 건 넣지 마세요. **한자를 칠 줄 알면 이 사이트가 필요 없거든요.**

한국 윈도우에서 중국어 입력기를 따로 깔아야 하고, 폰에서는 더 번거롭습니다. 검색창에는 `결정` 이나 `juyding` 같은 걸 치게 됩니다.
:::

---

## 3. 단어 상세 `/words/[id]`

**여기서 하는 일:** 단어 하나를 제대로 보기

| 위에서부터 | 뭐가 들어가나 |
|---|---|
| 큰 한자 | 화면 가운데, 아주 크게 |
| 병음 | 한자 바로 아래, 성조 기호 포함 |
| 뜻 | 한국어 뜻 · **품사** |

:::caution[품사를 빼면 안 됩니다]
공식 목록에 **같은 한자가 두 번** 나옵니다. 화면에서도 그대로 두 번 보여요.

| 한자 | 병음 | 품사 | 뜻 |
|---|---|---|---|
| 把 | bǎ | 개사 | ~을 |
| 把 | bǎ | 양사 | 자루 |
| 背 | bēi | 동사 | 업다 |
| 背 | bèi | 명사 | 등 |

**품사가 없으면 목록에서 똑같은 카드가 두 개 있는 것처럼 보입니다.** 버그로 오해하기 딱 좋아요. 목록 화면에도 품사를 같이 보여주세요.
:::
| 예문 | 한자 / 병음 / 해석 세 줄 |
| 버튼 2개 | "외웠어요" · "아직이요" |
| 맨 아래 | "목록으로" 링크 |

**이 페이지가 사이트의 핵심입니다.** 처음 아이디어의 "단어, 문장, 해석"이 전부 여기 있어요.

---

## 4. 학습 `/study`

**여기서 하는 일:** 카드를 넘기며 외우기

| 순서 | 화면 |
|---|---|
| 1 | 한자만 크게 보임. "뜻 보기" 버튼 |
| 2 | 누르면 병음·뜻·예문이 펼쳐짐 |
| 3 | "외웠어요" / "아직이요" 중 하나 누름 |
| 4 | 다음 카드로 |
| 10장 끝 | "오늘 10개 중 7개 외웠어요" 결과 화면 |

:::note[3회차에는 여기까지만]
카드를 눌러도 아무 일이 안 일어나도 됩니다. 화면만 있으면 돼요.

실제로 넘어가고 저장되는 건 4회차입니다.
:::

| 폰 기준 | 가로로 나열하지 않기. 세로 한 칸으로 |

---

## 3회차에 확인할 것

3회차가 끝나면 이게 다 돼야 합니다.

- [ ] 홈에서 단어 카드를 누르면 상세로 넘어간다
- [ ] 상세에서 "목록으로"를 누르면 단어장으로 온다
- [ ] 맨 위 메뉴로 세 페이지를 다 갈 수 있다
- [ ] 목록 화면에 가짜 단어 3개가 들어 있다
- [ ] 브라우저 탭 이름이 "Create Next App" 이 아니다

하나라도 안 되면 [06-checkpoints.md](06-checkpoints.md) 를 보세요.
