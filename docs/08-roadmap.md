# 앞으로 · 10분에서 어디까지

> 지금 만드는 건 **1단계뿐**입니다. 나머지는 여기 적어두고 손대지 마세요.
> 적어두는 것만으로 충분해요. 안 적어두면 자꾸 지금 하고 싶어집니다.

| 2 · 자료 늘리기 | 973단어 전체 · 검증 · 익명 로그인 | 1단계가 2주 굴러간 뒤 |

## 1단계 · 출퇴근 10분 (지금)

**되면 성공:** 폰으로 열어서 10단어를 넘기고, 다음 날 열었을 때 어제 외운 게 기억돼 있다.

여기서 확인하려는 건 사이트가 아니라 **파이프라인**입니다.

- CSV → SQL → Supabase → 화면까지 한자가 안 깨지고 오는가
- 같은 시드를 두 번 돌려도 100줄인가
- 버튼을 두 번 눌러도 `progress` 가 한 줄인가

이 셋이 확인되면 나머지는 데이터를 늘리는 일일 뿐입니다.

## 2단계 · 자료 늘리기

### 973단어 전체

지금 100개는 공식 목록 앞에서부터(`L3-0001`~`L3-0100`) 자른 것입니다. 100개씩 늘리면 됩니다.

**한 번에 973개를 만들지 마세요.** AI가 뒤로 갈수록 대충 만들고, 병음 성조부터 틀리기 시작합니다.

### 검증 · 이때 꼭 하기

| 확인할 것 | 어떻게 |
|---|---|
| 한자·병음·품사가 공식 목록과 같은가 | 원본 목록과 대조 (자동으로 가능) |
| 한국어 뜻이 맞는가 | 사전과 대조 |
| **예문이 자연스러운가** | **사람이 봐야 합니다** |

**마지막 줄이 자동화가 안 됩니다.** 중국어를 아는 사람이 필요해요. 검수한 만큼만 사이트에 올리는 게 맞습니다.

> 검수 상태를 표에 적어두면 편합니다. `words` 에 `verified boolean default false` 를 하나 추가하고, 화면에서는 `verified = true` 만 보여주는 식으로요.

### 익명 로그인

지금은 로그인이 없어서 폰과 노트북의 진도가 따로 놉니다. 그리고 `progress` 를 누구나 읽을 수 있어요.

Supabase Auth의 **익명 로그인(anonymous sign-in)** 을 켜면 둘 다 풀립니다. 회원가입 화면 없이도 진짜 사용자 ID가 생기거든요.

그러면 RLS 정책을 이렇게 바꿀 수 있습니다.

```sql
-- 내 줄만 읽고 고칠 수 있게
using (auth.uid()::text = user_key)
```

**남에게 링크를 주기 전에 이걸 하세요.**

## 3단계 · 1시간용

여기서 막히는 건 코드가 아니라 **자료**입니다. 문제 유형이 늘면 필요한 데이터도 늘어요.

| 문제 유형 | 새로 필요한 데이터 |
|---|---|
| 뜻 고르기 (4지선다) | 없음 — 다른 단어에서 오답을 뽑으면 됨 |
| 병음 고르기 | 없음 |
| 빈칸 채우기 | 예문에서 **어느 글자가 그 단어인지** 위치 정보 |
| 문장 배열 | 예문을 어절 단위로 쪼갠 것 |
| 듣고 고르기 | 소리 (5단계) |

**빈칸 채우기가 제일 값싸게 늘릴 수 있는 유형입니다.** 예문에 이미 그 단어가 들어 있으니, 그 자리만 가리면 돼요. 지금 데이터로 바로 됩니다.

## 4단계 · 게임

표 하나만 더 만들면 됩니다.

```sql
create table public.attempts (
  id          uuid primary key default gen_random_uuid(),
  user_key    text not null,
  hsk_id      text not null references public.words(hsk_id),
  quiz_type   text not null,     -- 'meaning' | 'pinyin' | 'blank'
  is_correct  boolean not null,
  answered_ms integer,           -- 몇 밀리초 만에 답했는지
  created_at  timestamptz not null default now()
);
```

`progress` 와 다른 점: **`progress` 는 한 줄만 남기고, `attempts` 는 계속 쌓입니다.** 게임은 기록이 쌓여야 성립하거든요.

여기서 나오는 것들 — 연속 정답, 오늘의 점수, 자주 틀리는 단어, 반응 속도.

> `answered_ms` 를 처음부터 넣어두세요. 나중에 추가하려면 과거 기록이 전부 비어 있게 됩니다.

## 5단계 · 말하면서 풀기

**여기만 기술적으로 진짜 어렵습니다.** 미리 알고 계시는 게 좋아요.

### 소리 내주기 (읽어주기)

브라우저에 내장된 음성 합성 기능을 쓰면 공짜입니다. 다만 **기기에 중국어 음성이 깔려 있어야 소리가 납니다.**

| 기기 | 상태 |
|---|---|
| 아이폰 · 안드로이드 | 대체로 중국어 음성이 있음 |
| 한국어 윈도우 | **없는 경우가 많음.** 언어 팩을 따로 깔아야 함 |

**노트북에서 조용하다고 고장난 게 아닙니다.** 이걸 모르면 하루를 날립니다.

돈을 조금 쓰면 서버에서 음성 파일을 만들어 미리 저장해두는 방법도 있어요. 973개면 한 번만 만들면 되니 오히려 이 쪽이 깔끔할 수 있습니다.

### 알아듣기 (내 발음 채점)

브라우저 음성 인식은 중국어를 지원하지만 **브라우저를 많이 가립니다.** 그리고 인식 결과가 맞았는지 판정하는 게 생각보다 까다로워요 — 성조가 틀려도 글자는 맞게 인식되는 경우가 많거든요.

**"발음 채점"은 이 프로젝트의 마지막에 두세요.** 여기부터는 3주짜리 커뮤니티 커리큘럼 밖입니다.
